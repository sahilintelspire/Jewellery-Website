# AURA JEWELS | Handcrafted Artisan Jewellery Boutique

Modern 3D animated luxury eCommerce storefront built with **React**, **Vite**, **Tailwind CSS**, **Three.js**, and **Framer Motion**.

## Key Frontend Features
- **Interactive 3D Atelier Hero**: 360° drag-to-spin procedural Three.js Sakura Blossom Bracelet with a 4-stage interactive Craft Process animation.
- **3D & Motion Auth Experience (`/auth`)**: Interactive 3D faceted Rose Crystal Heart & Orbital Gold Rings emblem (`Auth3DCanvas`), Sign In, Registration, Forgot/Reset Password, and Google Sign-In/Register flow.
- **Protected Purchasing & Multi-Step Checkout (`/checkout`)**: Authentication guard before buying, saved Indian Delivery Address book (CRUD), Velvet Gift Packaging & Calligraphy Note, Coupon Codes (`AURA10`, `WELCOME200`, `FREESHIP`), Razorpay Test Modal, and COD confirmation.
- **Customer Account & Live Order Tracking (`/account`)**: 5-stage studio-to-delivery order progress bar, Reorder/Cancel controls, Saved Addresses, and Profile editor.
- **Catalog & Discovery**: Live global search overlay, filtered Collections (`/collections`), Product Customizer with size & A–Z initials + customer reviews (`/product/:id`), Wishlist (`/wishlist`), Custom Studio (`/custom-order`), Policies, and animated `404` page.

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
